# StruBrowser

浏览器端 BIM 工作台（Revit 类工作流的 Web 实现）。当前版本 **v0.9 · BIM 内核 + Revit 式通用编辑 + 图层/材质管理 + 参数关联 + 明细表/IFC4 + 服务端协作 + AI 建模**：
构件是「类型 + 参数 + 标高约束」的族实例，几何实时生成；修改命令按 Revit 的「选择 → 命令 → 视口取点 → 幽灵预览 → 完成」工作，
类型尺寸可绑定公式并由全局参数驱动，图层/材质/参数都随项目保存并参与多人实时同步。

> 长期目标与差距分析见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)：复刻 Revit 核心工作流
> （标高/轴网 → 参数化构件 → 视图/图纸 → 明细表 → 互操作 → 协作），不做功能对等复刻。

## 已实现

**BIM 语义**
- 标高：增删改名、改高程；构件以「标高 + 偏移」定位，改标高全模型联动。
- 轴网：绘制、命名、删除，平面/三维中可见；**端部为圆形气泡并显示轴网名称**（落在标高平面内，会被构件遮挡）。
- 参数化构件：墙（基线 + 类型厚度 + 顶部标高）、柱（定位 + 截面类型 + 顶部标高）、楼板（矩形轮廓 + 类型厚度）。
- 类型 / 实例：类型持有尺寸与材质，实例持有位置与标高约束；改类型参数同步全部实例（面板显示共享实例数）。
- **参数关联更新**：项目级全局参数 + 公式（如 `标准墙厚 = 基准厚度 * 墙厚系数`），类型尺寸与实例尺寸可用 `fx` 绑定公式；
  改一个驱动参数，所有下游参数、类型、实例、几何、明细表与 IFC 导出按依赖拓扑序一次算完；循环依赖会报错并保持原值。
- 参数化体量：拉伸、旋转、长方体、圆柱、球、棱锥，放置后可在属性面板改尺寸，几何实时重建。
- **图层管理**：6 个默认图层（默认 / 墙 / 柱 / 板 / 导入几何 / 参照），逐层控制显示、锁定、颜色替换、透明度；
  「当前图层」决定新构件归属；可新建、重命名、删除、指派选中构件；「模型类别」页支持按类别可见性/图形替换。
- **材质浏览器**：颜色、不透明度、粗糙度、金属度、说明；支持新建/复制/删除、搜索、引用统计、
  应用到选中图元（覆盖）或族类型（全部实例联动）、清除图元覆盖。删除材质时引用自动改指默认材质。
- 显示优先级：图层颜色替换 > 类别颜色替换 > 图元材质 > 类型材质 > 导入几何自身颜色；
  可见性：构件自身可见 ∧ 图层可见 ∧ 类别可见；锁定：构件 Pin ∨ 图层锁定。
- 撤销 / 重做：不可变文档快照栈（50 步），图层/材质/参数操作同样可撤销。

**视图与交互**
- 三维视图（透视 / 平行投影）与每个标高一张平面视图（正交俯视，锁定旋转）。
- 视口绘制：墙 / 轴网两点定位，柱单击落位，楼板两点拉矩形；带预览、0.1 m 吸附。
- **绘制时可输入坐标**：选中绘制工具后，视口左上角出现坐标条 —— 直接键入选点 **X / Y**（单位米，也接受 `3600mm`、`360cm`），
  按 Enter 或「确定」落点；两点构件（墙 / 板 / 轴网 / 体量）取完第一点后可改用 **长度 + 角度**（自 +X 逆时针）定第二点，
  也可点 **⌖** 把当前光标位置填进 X / Y。柱只需一个放置点；坐标条右上角 ✕ 或 Esc 取消（Esc 先退第一点，再退工具）。
- 绘制时支持**对象捕捉**：端点 / 中点 / 交点（墙、板、柱、轴网），靠近时高亮方框并显示捕捉类型；
  可在「账户中心 → 软件设置」里关闭对象捕捉或网格吸附。
- 项目浏览器 / 属性栏之间的分隔条可**拖动调整宽度**（双击恢复默认），宽度按设备记忆；
- 选择：左键点选、**框选**（左键单击空白处开始 → 移动鼠标 → 再次单击完成）、Shift 加选、可见性开关、
  缩放至全部 / 缩放至选中构件；反向框选（右→左）为相交选择。
- **Revit 式通用编辑**：选择 → 点命令 → **上下文选项栏**（约束/复制/多个/个数/移动到最后一个/角度/比例）→
  视口内取基点、终点 → **幽灵预览 + 临时尺寸**（可直接键入数值）→ 单击或 Enter 完成，Esc 逐级退出。
  命令覆盖：移动 MV、复制 CO、旋转 RO、镜像·绘制轴 MM、镜像·拾取轴 DM、线性阵列 AR、环形阵列 RA、
  对齐 AL、偏移 OF、缩放 SZ、修剪/延伸 TR、拆分 SL、测量 DI、锁定 PN / 解锁 UP、删除 DE。
  没有选择时点命令进入「等待选择」，选好后按 Enter 或直接取点继续。
- 视口操作：**左键拖拽即时旋转视角**（无需等待，按下移动就转）；轻点构件为选中，空白处**轻点两下完成框选**
  （第一下落下起点、移动鼠标、第二下完成，左→右完全包含 / 右→左相交）；Ctrl/Cmd + 拖拽构件为复制；
  中键平移，滚轮缩放；右键菜单（选择所有 / 选择同类型 / 取消选择 / 最近修改命令）；平面视图锁定旋转。
- **视角立方体**：视口右上角无边框悬浮，实时显示当前朝向；**直接拖拽立方体即旋转视角**，
  点 **顶 / 底 / 前 / 后 / 左 / 右** 面平滑转到该标准视角，**双击**回到轴测；
  始终留在三维视图（透视/平行都不变），转完仍可继续在视口里自由旋转。
- 剪贴板：Ctrl/Cmd+C / V（连续粘贴逐次偏移）、Ctrl/Cmd+D；方向键微移 0.1 m（Shift 1 m）。
- **VV** 打开图层管理器、**MA** 打开材质浏览器、**GP** 打开参数关联管理器；Esc 先关弹窗，再退命令取点，最后清空选择。
- **弹窗是模态的**：打开后锁定主界面 —— 点遮罩空白不会关闭（卡片只轻微抖一下提示），全局快捷键暂停响应，
  Tab 焦点锁在弹窗内循环；用 ✕ / 取消 / 完成（或 Esc）关闭，关闭后焦点自动还给打开它的按钮。
- 全屏：顶部工具栏的 ⤢ 按钮（页面全屏，保留全部菜单）；再点一次退出。
  Chrome/Edge 进入全屏时会锁定 Esc（Keyboard Lock），**Esc 只用于取消选择、不会退出全屏**；
  Safari/Firefox 不支持该 API，Esc 仍会退出全屏（浏览器限制）。
- 面板：顶栏 ▤ / ▥ 按钮或面板右上角 « / » 可收起项目浏览器与属性面板，收起后两侧竖条可重新展开；
  展开状态会记忆在浏览器里。
- 状态栏：光标坐标、当前标高与工具、构件数、三角面估算、角色与保存状态。

**服务端（Node + SQLite）**
- 注册 / 登录：scrypt 加盐密码、HMAC-SHA256 token（7 天）；单端口同时托管前端与 API。
- 成员与角色：`viewer` 只读、`editor` 可保存/建版本、`admin` 可改名/删项目/管成员/查审计。
- 文档 rev 乐观并发：两个会话同时保存时返回 409，前端提示「加载最新 / 覆盖保存」。
- 版本历史：不可变快照、标签、恢复（恢复生成新 rev，不删历史）。
- 审计日志：项目创建、改名、保存、版本、成员操作。
- 前端自动探测 API：可用则服务端模式（登录），否则回退本地 IndexedDB 单机模式。

**实时协作（WebSocket）**
- 打开同一项目的成员自动进入房间：在线头像、加入/离开提示，角色实时生效（被降级后立即只读）。
- 编辑以「按构件 id 的差分」广播并落库：两人改不同构件互不覆盖，服务端是唯一 rev 来源。
- 断线自动重连（1s→8s 退避）；断线期间回退 HTTP 自动保存 + rev 冲突提示。
- 房间消息：`hello`（rev/文档/在线用户）、`presence`、`patch`、`sync`、`error`。

**AI 建模助手（文本 → BIM）**
- 顶部 **✦** 打开 AI 面板，用中文描述需求（例如“建一个 6×4 米、层高 3 米的房间”“把墙加厚到 300”“删除墙 1”）。
- AI 只输出**结构化建模指令**（标高/轴网/墙/柱/板/类型/删除），面板先展示将要做的修改，点「应用到模型」才写入。
- 默认 **Mock 模式**（本地关键词模拟，无需 key）；配置 `STRU_AI_PROVIDER=openai` + 兼容地址/模型/key 即可接真实模型。
- 服务端校验指令与权限（viewer 只读），写入新 rev + 审计，可撤销；应用后向协作房间广播，其他成员自动同步。
- 细节见 [docs/AI.md](docs/AI.md)。

**数据与交换**
- 文档 schema v2（含 `layers` / `categoryOverrides` / 材质物理属性 / `parameters` 与类型·实例 `formulas`）；本地模式 IndexedDB，服务端模式 SQLite；
  v1 网格文档、旧版无图层文档都会自动迁移并按类别归入默认图层。
- **模型导入**：glTF/GLB、OBJ、FBX、COLLADA(.dae)、STL、PLY、OFF、3DS、3MF、DXF（三维面）、SketchUp(.skp) 与 STEP/STP，
  导入前可选择向上轴与单位（详见[模型导入](#模型导入)）；导出 OBJ（Z-up → Y-up）。
- STEP/STP 导入：服务端模式下走 OCCT 转换器保留逐面颜色，纯浏览器模式回退 occt-import-js。
- **IFC4 导出**：IFCPROJECT / IFCBUILDING / IFCBUILDINGSTOREY 层级、IFCPOLYGONALFACESET 三角网格，
  并输出 `IFCMATERIAL` + `IFCRELASSOCIATESMATERIAL`（材质）与 `IFCPRESENTATIONLAYERASSIGNMENT`（图层）。
- **构件明细表**：长度 / 面积 / 体积 / 三角面按真实几何统计，可导出带 BOM 的 CSV（Excel 直接打开中文不乱码）。
- 图层与类别可见性替换写入协作差分（客户端 `collab/diff.ts` 与服务端 `server/validate.js` 均支持），多人编辑实时同步。

## 一键启动

要求 Node.js ≥ 22.5（使用内置 `node:sqlite`）。**macOS 可在 Finder 里双击 `start.command`（本地开发）或 `启动隧道.command`（给外部访问）**，或在终端运行：

```bash
./start.sh                  # 开发模式：API 8787 + Web 5173，自动打开浏览器
./start.sh prod             # 生产模式：构建后用单端口 8787 运行
./start.sh tunnel           # 一键给外部访问：生产模式 + 公网隧道，打印可分享链接
STRU_NO_OPEN=1 ./start.sh   # 不自动打开浏览器
PORT=9000 WEB_PORT=9001 ./start.sh   # 自定义端口
```

脚本会自动完成：检查 Node 版本 → 首次运行时 `npm install` → 检测并复用已在运行的 API →
选择空闲端口 → 等待服务就绪 → 打开浏览器 → 把日志写入 `.logs/`；按 **Ctrl+C 一起停止**。
STEP 转换器未安装时会提示运行 `npm run setup:step`。

> **改了 `server/` 里的代码不用手动重启**：再次运行 `./start.sh` 时会比对 API 进程的启动时间与
> `server/**/*.js` 的最新修改时间，发现「进程比代码旧」就自动重启 API（`./start.sh restart` 则是无条件重启）。
> Node 不会热载服务端模块，这一步是必要的，否则复用旧进程会一直跑旧逻辑。

## 其他运行方式

```bash
npm install
npm run dev:all      # 同 ./start.sh（不自动开浏览器）
npm run server       # 只启动 API
npm run dev          # 只启动前端（探测不到 API 时自动使用本地 IndexedDB）
npm start            # 同 ./start.sh prod
npm run setup:step   # 可选：安装 STEP 服务端转换器（Python + cadquery-ocp，约 650 MB）
npm test             # 全量测试（自动拉起临时服务端，含图层/材质 49 项、参数关联 38 项、撤销栈 12 项内核断言）
```

首次打开需要注册一个账号（服务端数据库 `server/data/strubrowser.db`，已被 .gitignore 忽略）。
环境变量见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#10-服务端运行与配置)。

## 账户中心（右上角用户名）

点右上角的**用户名**进入账户中心——它不是弹窗，而是**独立整页**：左侧品牌 + 导航，右侧面包屑、页面标题与内容，
铺满整个窗口；`Esc` 或右上角「← 返回工作台」回到原场景（工作台只是隐藏，文档与视角都不丢）。
顶部 **⚙** 直达「软件设置」，深链 `/?account=projects` / `/admin` 也可，地址栏会跟着当前页变化，刷新和分享都落在同一页。

左侧导航按权限分组，普通成员只看到「账号 / 工作区」，系统管理员多出「系统管理」整组：

| 分组 | 页面 | 说明 |
| --- | --- | --- |
| 账号 | 个人资料 | 改显示名称、查看邮箱 / 角色 / 注册时间、退出登录 |
| 账号 | 登录与安全 | 修改密码（需旧密码 + 两次确认 + 强度提示） |
| 工作区 | 我的项目 | 参与过的全部项目，按最近修改排序，可重新打开继续编辑 |
| 工作区 | 软件设置 | 本机显示与交互偏好（见下） |
| 系统管理 | 用户管理 | 顶部统计（账号总数 / 管理员 / 成员）、搜索与筛选、行内改名、创建账号、重置密码、授予/收回管理员、删除 |
| 系统管理 | AI 设置 | 提供方、接口地址、模型、API Key、测试连接 |
| 系统管理 | 系统与审计 | 运行概览、全站项目、审计日志 |

- **我的项目**：每行显示角色（管理员 / 可编辑 / 只读）、rev、构件数、最近更新时间；支持搜索、重命名、
  删除（项目管理员），「打开」会切换当前文档（当前项目显示「编辑中」）。
- 运维兜底：唯一管理员忘记密码时，在服务端执行 `npm run reset-password -- 邮箱 新密码`。
- 旧入口兼容：`/admin` 会自动打开工作台并定位到「系统与审计」。

**软件设置**（账户中心 → 软件设置）按设备保存在浏览器（localStorage）：

- **颜色**：选中高亮色、视口背景色、轴网线颜色、轴网气泡颜色（#RRGGBB，即改即生效）。
- **显示**：地面参考网格、工作平面网格、轴网、轴网气泡、坐标轴指示器、光标坐标、构件/三角面统计，均可单独开关。
- **交互**：绘制吸附步长（0.01 / 0.05 / 0.1 / 0.25 / 0.5 / 1 m）、对象捕捉（端点/中点/交点）、网格吸附、
  **旋转惯性**（关闭后松开鼠标立即停住）、**渲染分辨率**（50%–150%，弱显卡/远程桌面建议 75%）、
  **界面字号**（90%–140%，高分屏或小字看不清时调大）。
- **恢复默认**：颜色卡片右上角一键还原全部显示与吸附设置。
- 软件设置不依赖服务端，本地模式同样可用；切换项目或账号都不会丢失。

## 多并发 / 多实例

当前是单实例架构（Node + SQLite + 内存协作房间），单实例可支撑几十人协同。要做多机/数百并发，
需要 Postgres + Redis（共享存储与协作总线）+ 粘性会话，完整分析、目标架构、分阶段改造清单见
[docs/MULTI_INSTANCE.md](docs/MULTI_INSTANCE.md)。

已准备好的并发保障：实例标识、`/api/ready`、SIGTERM 优雅退出、WS 背压与消息限流、AI/STEP 重接口限流，
以及压测脚本：

```bash
BASE=http://127.0.0.1:8787 USERS=20 ROUNDS=20 npm run load-test
```

## 系统管理（系统管理员）

入口在账户中心的「系统管理」组：**用户管理 / AI 设置 / 系统与审计**；Ribbon「管理 → 用户与系统」也能直达。
普通账号看不到这一组，接口侧仍由 `requireSystemAdmin` 兜底校验（前端隐藏只是体验，权限在服务端）。

- **用户管理**：查看全部账号（邮箱、角色、项目数、参与数、注册时间），支持搜索与「全部 / 管理员 / 普通成员」筛选；
  创建账号（可一键生成随机初始密码）、改名、重置密码（生成随机密码并复制）、设为/取消管理员、删除。
  保护规则：至少保留一名系统管理员；不能删除自己；拥有项目的用户需先处理项目；删除用户会级联移除其项目成员关系。
- **AI 设置**：提供方（Mock / OpenAI 兼容）、接口地址、模型、API Key、超时；支持“测试连接”。
  - Key **AES-256-GCM 加密**存在 SQLite（密钥由服务端 `STRU_SECRET` 派生），接口只返回 `****末4位`，永不下发明文。
  - 界面保存的配置优先于环境变量，保存后立即生效（无需重启）。
  - 环境变量仍可用：`STRU_AI_PROVIDER / STRU_AI_BASE_URL / STRU_AI_MODEL / STRU_AI_API_KEY`。
- **系统与审计**：用户数 / 管理员数 / 项目数、文档总大小与数据库大小、审计事件数、在线协作人数与房间、
  运行时长、版本、Node 版本、数据目录、注册开关、登录限流、AI 状态、STEP 转换器状态；
  全站项目列表（所有者、构件数、rev、大小、成员数、更新时间，可搜索、可删除）；
  系统级审计（注册、项目、成员、文档、版本、AI、管理操作），支持按 action 过滤与分页。
- 接口：`/api/me`（PATCH 改名）、`/api/me/password`（POST 改密码）、`/api/admin/users`、
  `/api/admin/settings/ai(.test)`、`/api/admin/overview|projects|audit`（管理接口均需系统管理员）。

## AI 建模助手

- 默认 Mock 模式，无需任何 key：点顶部 **✦** 输入需求 → 查看指令 → 应用。
- 接真实模型（OpenAI 兼容，仅服务端持有 key）：

```bash
export STRU_AI_PROVIDER=openai
export STRU_AI_BASE_URL=https://api.deepseek.com/v1   # 或 OpenAI / 通义 / 本地 Ollama
export STRU_AI_MODEL=deepseek-chat
export STRU_AI_API_KEY=sk-...
npm run server   # 重启后生效
```

> 也可以不碰环境变量：用系统管理员账号打开**账户中心 → AI 设置**，在界面里填 Key 并“测试连接”。

- **thinking 模型兼容**：请求不再强制 `tool_choice`（qwen3 / GLM 等 thinking 模式会返回
  `400 Thinking mode does not support this tool_choice`）。若该模型连 `tools` 都不接受，
  会自动降级为「纯 JSON 输出」的一次重试，解析逻辑与工具调用一致，无需改配置。
  另外：thinking 模型生成一个几十个特征的精细造型常要 1–4 分钟，默认超时已从 60 s 放宽到
  **180 s**（旧的 60 s 配置会在启动时自动升级；也可在「账户中心 → AI 设置」改到 300 s）。

- **流式输出中间过程**：AI 面板走 `/api/projects/:id/ai/plan/stream`（SSE），实时显示
  “思考过程 / 输出草稿 / 正在生成特征树（N 字符）/ 已用时间”，可随时点「停止」。
  上游是逐 token 返回的，服务端按 100 ms 合并再推，既不卡也不刷屏；超时改成
  “180 s 没有收到任何字节”的空闲超时，thinking 模型连续思考几分钟也不会被误杀。
  实测 deepseek-v4-pro 造无人机：**首字节 1.2 s**、思考约 195 s、总耗时 206 s ——
  以前这 195 s 是纯空白，现在是持续滚动的过程。
  非流式接口 `/ai/plan` 保留给脚本与旧客户端，服务端没有流式路由时前端自动退回。

- **传图 / 传文件建模**：AI 面板可上传 / 粘贴 / 拖入图片（最多 4 张，单张 4 MB，前端会先压到长边 1280），
  输入框左边的 **＋** 也能收文本文件（`txt / md / json / csv / log / yml / 代码` 等，单个 1.2 万字、合计 2.4 万字），
  内容作为参考资料拼在这一轮需求后面一起发给模型，并随消息落库；聊天里只显示文件条，点开才看正文。
  图片先由视觉模型读成结构化规格（物体、包围盒、零件清单、尺寸、材质色值、细节），
  再交给建模模型生成一棵特征树——因为主力建模模型多是纯文本的，直接塞图只会得到
  「我无法查看图片」。主模型自己支持图片时则直接内联，跳过描述阶段。
  是否读图由服务端判断：主模型自己支持图片就内联直传；不支持时才用 AI 设置里**手动勾选**的
  「独立视觉模型」（模型名自己填，可单独配接口地址与 Key，默认不启用，也不会自动挑模型）。

- **多轮对话与历史会话**：需求与生成结果都会落库（`ai_conversations` / `ai_messages`），面板顶部的会话条
  可以切换 / 新建 / 重命名 / 删除历史会话——关掉面板、刷新页面、换设备都能接着聊。参考图只存缩略图，原图不进库。

- **上下文按 token 预算压缩**：每次请求按模型窗口（128k / 200k / 1M，按模型名推断，也可在 AI 设置里填）
  分配额度，分给「更早对话的滚动摘要 / 项目上下文 / 最近原文」。项目上下文是**结构化裁剪**——先降特征数
  （48→24→12→6）再少列构件，省略多少会明确告诉模型，而不是把 JSON 切成半截。对话超过 18 条或 6k token
  时服务端自动把更早的部分压成结构化备忘（目标 / 关键参数 / 已完成的修改 / 未决问题 / 偏好，最近几条保留原文）；
  面板会话条显示 `12.4k / 128k` 占用，超过 65% 变黄、85% 变红，点一下或按「压缩」立刻压一轮并告诉你压了多少条。

- **让 AI 看自己的成品**：面板底部「让 AI 看当前模型」默认打开，发送时会把当前三维视口截一张图一起发过去，
  模型因此能对着自己做出来的东西判断「像不像」再改。模型不能读图（且没启用独立视觉模型）时这个开关自动禁用；
  截图是发送前现取的，不会拍到几何重建到一半的画面。项目里还没有构件、或截出来是一整张纯色时**不会截**，
  气泡里只挂一个「已附当前视图」的小提示（这张图是给模型看的，不是用户粘贴的参考图，也不落库）。

- **AI 自己改、自己转视角看、不满意继续改（自检闭环）**：需求发出去以后，AI 不再只是「生成一次就交差」——
  它给的每条 `ops` 会立刻写进模型，然后自己把视口转到要看的视角（前视 / 右视 / 俯视 / 任意方位角，最多 4 个）
  截图回灌，看着图判断「比例对不对、零件有没有悬空穿模、该有的件缺不缺」，发现问题就用 `editFeature`
  精确修正，再看，直到它自报 `done`。整个过程最多 5 步，**随时可以点「停止」**（发送键在运行中变成红色停止键），
  已经应用的每一步都是一个 rev，可 Ctrl/Cmd+Z 撤销。面板底部「自动改并自检」默认打开，关掉就只给建议、
  由你手动应用。点「转一圈检查」就是让它走一轮这套闭环。
  看哪个角度、看多近都由它自己定：视角既可以是前视/右视/俯视，也可以是任意方位角+仰角；
  想凑近看细节就带 `focus`（构件名、id 或造型特征名）和 `zoom`（取景倍数）——
  比如「一张整机等轴测 + 一张夹头特写 ×2.5」。

- **面板可拖动、可吸附成右侧固定栏**：按住标题栏任意拖动（位置与大小记在 `localStorage`，
  下次打开/刷新保持原样）；拖到窗口右边缘会出现虚线预览，松手即吸附为**右侧固定栏**——
  贴边、直角、从功能区下方一直延伸到状态栏，工作区自动让出这一条，视口与属性栏不会被盖住。
  固定栏左边缘可拖动调宽（320–760 px），标题栏的 ⇱/⇥ 按钮或双击标题栏都能在「浮动 / 固定」之间切换，
  往左拖出一段距离也会就地变回浮窗。

- **上游“HTTP 200 + 空响应体”**：非流式通道两次拿不到 JSON 且响应不是网页时，会自动
  **换流式通道再试一次**（两条通道在上游常常不是同一套实现）；空体/截断/429/5xx 另有重试，
  返回网页则直接提示 baseUrl 少了 `/v1` 或被网关拦截。失败原因会写进 `.logs/server.log`
  的 `[ai] plan 失败 …` 一行（含状态码与响应体片段）。

- **任意造型也走这条通道**：`addSolid` 直接携带特征树（14 种形状：圆角盒 / 长方体 / 圆柱 / 圆管 /
  胶囊 / 球 / 椭球 / 圆锥 / 圆环 / 任意轮廓拉伸 / 旋转体 / 多截面放样 / 变截面扫掠 / 点集凸包，
  外加子装配 + 平移旋转缩放 + 线性/圆周阵列 + 布尔切除），
  `addFeature` / `editFeature` / `deleteFeature` 可以只改某个特征。
  模型返回的是 JSON，**不写代码、也没有「生成代码 → 再编译」**：指令进文档，几何由
  `src/bim/solid.ts` 在渲染时实时求值，改一个尺寸不用重建整棵树。
  曲面件用平滑法线、盒体保留硬棱；切除用 BVH 加速的布尔（three-bvh-csg），
  三四十个特征、十来个孔的整机模型求值 200–300 ms，不会把浏览器卡住。
  说一句「造一台四翼螺旋桨无人机」就能得到圆角机身 + 整流罩 + 圆管机臂 + 外转子电机 +
  翼型桨叶（多截面放样、带桨距）+ 弯曲起落架 + 云台 + 天线，共 31 个特征；
  接着说「机臂加长到 30cm」只会改那一个特征。

- **整机构图是一等公民**：提示词里写死了「一个产品 = 一个构件 = 一棵特征树」——
  所有零件放进同一次 `addSolid`，相邻零件真实重叠 3 mm 以上，`translate` 是几何中心、
  管件沿 X 轴要 `rotate: [0,90,0]`，外壳截面要扁（`height ≈ depth × 0.6–0.8`）、
  倒圆取短边的 1/8–1/6。圆角盒也换成了真正的「圆角矩形轮廓放样 + 端部圆弧」，
  不再是超椭球近似 —— 侧面是平的、只有棱边带 R，倒圆给大一点也不会整块变蛋形。
  参考实现 `shared/models/screwdriver.json`（14 特征 / 7 材质的一体化电动螺丝刀）同时是
  提示词 few-shot、Mock 分支和「设计库」模板。

- **逐零件材质**：每个特征可带 `material`（预设名如 `"aluminum"`，或
  `{ color, roughness, metalness, opacity }`），求值时按材质分组、用 `geometry.groups` 多材质渲染；
  同一材质自动合并成一个材质槽。预设库（铝 / 不锈钢 / 碳纤维 / 塑料 / 橡胶 / 玻璃 / 铜 / 烤漆 / 陶瓷 / 木材）
  在 `shared/materials.js`，AI、模板、界面下拉框共用。视口加了 `RoomEnvironment` 环境贴图 + ACES 色调映射，
  金属与粗糙度才有真实的反射和高光；「把机身改成深灰」用 `editFeature` 的 `material` 补丁即可，
  也可以在特征树编辑器里直接选预设 / 取色 / 拖粗糙度和金属度滑块。

- 指令表、特征 schema、安全边界、provider 配置与测试见 [docs/AI.md](docs/AI.md)。

## STEP 面颜色（服务端 OCCT 转换器）

浏览器端 `occt-import-js` 在「装配实例 + 面着色」的 STEP 上会丢面颜色（上游 [#68](https://github.com/kovacsv/occt-import-js/issues/68)）。
项目内置了一个服务端转换器：上传 STEP → Python + OCP 读 XCAF 样式表 → 输出带**逐面顶点颜色**的二进制网格。

- **安装**：`npm run setup:step`（创建 `server/convert/.venv` 并安装 `cadquery-ocp`），安装后重启服务端；
  启动日志会显示 `STEP 转换器：可用（…）`。
- **使用**：服务端模式下导入 STEP 会先走转换器，提示「正在服务端解析 STEP（含面颜色）」；
  成功后构件的来源标记为「STEP 导入（服务端 OCCT，面颜色）」，消息里显示面带色数量。
  转换器不可用或失败时自动回退浏览器解析，并提示颜色可能丢失。
- **状态**：`GET /api/convert/step/status`。
- **实测**：121 MB 吊车模型 → 264,276 三角面 / 18 MB 网格 / 约 2.5 分钟，**21,178 / 21,394 个面带色**；
  同一文件用浏览器导入器时面颜色为 0。
- **配置**：`STRU_PYTHON`（解释器）、`STRU_MAX_STEP_BYTES`（默认 256 MB）、`STRU_CONVERT_TIMEOUT_MS`（默认 15 分钟）。

注意：转换器只在**服务端模式**生效；纯浏览器（本地模式）仍使用 occt-import-js，面颜色会丢失。

## 模型导入

「管理 → 导入模型」支持 12 种格式，也可以直接把文件**拖进窗口**（可多选，`.gltf` 请连同 `.bin` / 贴图一起拖入）。

| 格式 | 扩展名 | 轴向 / 单位 | 说明 |
| --- | --- | --- | --- |
| glTF / GLB | `.glb` `.gltf` | Y-up / 米 | 保留材质基色与节点层级；Draco/meshopt 压缩会提示 |
| OBJ | `.obj` | Y-up / 米 | 最通用；`.mtl` 不自动加载，按基色显示 |
| FBX | `.fbx` | 读 GlobalSettings | 读 `UpAxis` 与 `UnitScaleFactor`（cm 基准），二进制 / ASCII 都支持 |
| COLLADA | `.dae` | 读 `<up_axis>` / `<unit meter>` | SketchUp 导出首选，单位能对上 |
| STL | `.stl` | Z-up / 未知 | 二进制 / ASCII；无材质，统一默认色 |
| PLY | `.ply` | Y-up / 未知 | ascii 与 binary，保留顶点色；点云会明确拒绝 |
| OFF / COFF | `.off` `.coff` | Y-up / 未知 | 多边形按扇形三角化，COFF 保留顶点色 |
| 3DS | `.3ds` | Z-up / 未知 | 3D Studio 老格式 |
| 3MF | `.3mf` | Z-up / 毫米 | 按规范默认毫米换算 |
| DXF | `.dxf` | Z-up / 读 `$INSUNITS` | 只导入 3DFACE / POLYLINE 网格 / MESH；线框会统计并提示忽略 |
| SketchUp | `.skp` | 读 `meta.dat`（米 / 厘米 / 毫米 / 英寸）/ Z-up | CFB 与 VFF(ZIP) 两种容器都认，见下方说明 |
| STEP / STP | `.step` `.stp` | Z-up / 米 | 走 OCCT（服务端可保留逐面颜色），见上一节 |

**导入前确认轴向与单位**：解析完成后会弹出确认框，显示构件数、三角面数、原始尺寸与「导入后尺寸」，
可切换向上轴（Y→Z 旋转 90°）和单位（自动 / 米 / 毫米 / 厘米 / 英寸 / 英尺）。
无单位格式的「自动」按包围盒推测（≥2000 → 毫米，≥200 → 厘米，其余按米）。

**SketchUp `.skp` 的边界**：几何数据 `model.dat` 是 Trimble 专有编码，没有公开规范、也没有可用的 JS 解析器，
所以本项目**不会假装能直接读几何**。但容器本身要认全，否则会把正常文件误判成「不是 SketchUp 文件」——
`.skp` 有两种容器，两种都支持：

| 容器 | 特征 | 典型来源 |
| --- | --- | --- |
| OLE 复合文档（CFB） | 头 8 字节 `D0 CF 11 E0 A1 B1 1A E1` | SketchUp 桌面版另存的普通 `.skp` |
| VFF（ZIP） | `FF FE` + UTF-16 的 `SketchUp Model` + `{版本}` + `VFF`，后接 ZIP（前缀 65 字节） | Trimble 在线服务 / 渲染服务产出的 `.skp` |

导入时会：解析容器（CFB 读 FAT / DIFAT / mini stream / 目录树；ZIP 按 local file header 顺序扫描，
因为这类 ZIP 的中央目录偏移是按「没有那 65 字节前缀」写的，系统 `unzip` 会报 `missing 2 bytes`）→
读 `meta.dat`（老版是 XML，新版是 `tag(u16) + len(u32) + value` 的二进制 TLV）拿版本 / 单位 / 内部记录的原始路径 →
提取内嵌预览图 `meta/preview_thumbnail.png` → 统计材质贴图 → 列出容器条目，
然后给出明确的转换步骤（SketchUp：文件 → 导出 → 三维模型 → COLLADA / OBJ / glTF）。导出的文件拖回来即可，颜色与层级都能保留。

已用 `model/` 下两份真实文件验证：`Pavilion+Chinese+otter.skp`（21.0.0 / Millimeter / 37 个材质 / model.dat 7.6 MB）、
`Chinese-style+pavilion.skp`（26.2.0 / Centimeter / 5 个材质）；两者都是 VFF 容器，预览图与元信息都能读出来。

测试：`npx esbuild scripts/import-test.ts --bundle --platform=node --format=esm --outfile=.tmp/import-test.mjs --log-level=warning && node .tmp/import-test.mjs`
（每种格式现场生成一个立方体走完整管线；glTF 用 `downloads/pavilion-ref/pavilion.glb` 真实样例；SKP 用最小 CFB 容器 + 65 字节头接 ZIP 的 VFF 容器，各验一遍容器解析与元信息。）

## 图层管理 / 材质管理

入口：**视图 → 图层 (VV) / 材质**、**管理 → 图层管理 / 材质浏览器**、项目浏览器里图层/材质树右侧的 ⚙，
或直接按 **VV** / **MA**。所有改动立即反映到视口，并进入撤销栈与协作补丁。

**图层管理器**
- 「图层」页：显示 / 锁定 / 当前图层单选 / 重命名 / 颜色与「按图层颜色替换」/ 透明度 / 构件数 / 删除；
  工具栏可新建图层、全部显示、全部隐藏、把视口中选中的构件指派到指定图层。
- 「模型类别」页：按墙 / 柱 / 楼板 / 导入几何控制可见性、投影颜色替换与透明度，可一键恢复默认。
- 0 号默认图层不可删除；含构件的图层需先转移构件；删除时构件自动归到 0 号图层。
- 图层锁定后，其构件不可移动 / 复制 / 旋转 / 删除 / 改几何参数；属性面板、修改命令会给出明确提示。
- 左侧项目浏览器可直接点眼睛图标切换图层显示，锁定图层有 🔒 标记。

**材质浏览器**
- 左侧列表支持按名称/说明搜索，右侧实时预览球与参数编辑：名称、颜色、不透明度、粗糙度、金属度、说明。
- 「应用到选中构件」写入图元级材质覆盖；「清除图元覆盖」恢复类型材质；「应用到族类型」让全部实例联动。
- 材质引用数按「类型 + 图元覆盖」统计；删除材质时所有引用自动改指列表中的第一种材质，不留悬空 id。
- 玻璃等半透明材质在三维视口使用透明渲染；材质颜色也作为 IFC 材质关联的来源。

## 参数关联更新

入口：**管理 → 参数关联**、**图形 → 参数 (GP)**，或在属性面板的参数行点 **fx** 直接建公式；**GP** 快捷键随时打开。
参数是项目级数据，和图层/材质一样进撤销栈、进协作补丁。

**全局参数（「全局参数」页）**
- 新建/改名/删除参数，设置名称、值、单位（m / m² / m³ / rad / 无量纲 / 个）、分组与说明；
- 公式支持四则运算、幂、括号、19 个内置函数（`abs min max round floor ceil trunc sign sqrt pow exp log ln sin cos tan clamp if mod`）
  与单位字面量（`200mm`、`90deg`、`50%`）；求值器是自带的词法分析 + 递归下降解析，**不使用 `eval`**；
- 改名会自动改写所有引用它的公式与类型/实例关联；删除前会提示下游引用数。

**类型 / 实例参数关联（「类型参数关联」「实例参数关联」页）**
- 类型的尺寸参数（墙厚、柱截面宽/深、板厚）与构件的几何参数都可绑定公式，绑定后成为只读计算值；
- 实例公式除全局参数外还可用上下文变量：`标高`、`顶部标高`、`层高`、`长度`、`面积`、`厚度`、`截面宽`、`截面深`、`底部偏移`、`序号`；
- 属性面板的 **fx** 控件显示公式与实时预览，可「编辑」或「解除」关联恢复手动输入；类型参数改动仍按原有规则同步全部实例。

**联动与诊断（「依赖关系 / 问题」页）**
- 依赖图自动拓扑排序，按「全局参数 → 类型参数 → 实例参数」一次算完，无变化时保持文档引用不变；
- 循环引用、未知变量、除零等问题会列在问题面板并保留原值，不产生半更新状态；
- 「立即重算」可手动触发；每次保存/编辑后 `commit` 都会自动重算，并在状态栏提示「联动更新 N 项参数（M 个构件）」；
- 几何、属性面板、明细表、IFC4 导出都读取同一份文档，因此改一个驱动参数后全部自动跟随。

## 坐标约定

世界坐标 **Z-up，单位米**：X/Y 为平面坐标，Z 为高程；标高 `elevation` 即世界 Z 值。
导入的几何会居中、贴地，作为独立 `mesh` 构件保存，不参与类型/标高联动；
导入过程中会按文件声明的轴向与单位换算到 Z-up / 米。

## 常见问题

- **AI 面板报「请求失败（HTTP 500）」**：多半是 API 没起来或还跑着旧进程（Vite 代理连不上后端就会返回 500）。
  运行 `./start.sh restart` 重启到最新代码；`curl http://127.0.0.1:8787/api/health` 应包含
  `"features":["ai","collab","step-convert"]`。
- **远程访问卡、延迟高**：看底部状态栏「延迟 xxx ms」和「账户中心 → 软件设置 → 诊断」：
  渲染器是硬件 GPU 时，卡顿通常来自网络路径。建议把服务部署到离使用者更近的 VPS（香港/新加坡/内地），
  或用 Tailscale/ZeroTier 直连、同局域网直接访问；公网隧道（trycloudflare）的路径可能长达 300–1000 ms。
  静态资源已 gzip + 长缓存，文档 JSON 也会 gzip；渲染本身是本地的，转视角不受网络影响。
- **报「无法连接服务端（Failed to fetch）」**：API 进程已退出（被关闭/崩溃）。页面顶部会出现红色断连提示条，
  重启后会在 8 秒内自动恢复（也可点提示条里的“重新连接”）。
- **看不到用户管理 / AI 设置**：只有系统管理员可见。升级到本版本后**最早注册的用户会在服务端启动时自动成为管理员**
  （旧库没有管理员时），重启并刷新页面即可；也可以用 `STRU_ADMIN_EMAILS` 指定。
- **AI 提示未就绪**：在「账户中心 → AI 设置」里填入 Key，或设置 `STRU_AI_API_KEY`。
- **AI 报「非 JSON 响应 / 返回的是网页 / 响应体为空」**：这是上游（模型网关、反代、Cloudflare 隧道）没把接口数据完整返回，
  不是模型输出格式问题。服务端已显式 `stream:false`、能把 SSE 流拼回完整响应，并对 200 空体 / 网关错误页自动重试一次；
  仍失败时错误里会带 HTTP 状态与 content-type。常见原因：`baseUrl` 少了 `/v1`、网关超时把 200 换成错误页、
  免费额度限流。排查时看服务端日志里 `[ai] plan 失败 ... provider/baseUrl/detail` 一行即可定位。

## 已知限制与后续

- 协作采用按构件 id 的 LWW 合并，无 CRDT/OT、光标共享、评论与离线编辑合并（M6+）。
- 断线期间的编辑走 HTTP 保存，重连后按构件 id 覆盖服务端；大网格构件（STEP 导入）的补丁仍传输整块几何。
- 无门窗洞口、墙连接/剪切、草图约束与尺寸标注（M3）。
- 平面视图尚无剖切范围与填充（M4）；明细表与 IFC4 导出已可用，但 IFC 导入、视图样板与图纸尚未实现（M5）。
- 图层是项目级（非按视图保存），暂不支持视图样板、过滤器规则表达式与图层线型/线宽。
- 参数为项目级，暂不支持跨项目共享参数、族参数/类型目录与参数化的阵列约束；重算按依赖图单次拓扑序执行，不做迭代收敛。
- 文档整包存 SQLite，大网格（STEP 导入）尚未外置到对象存储；服务端为无类型 JS，接入 PostgreSQL 时补齐。
- 开放注册默认开启（`STRU_ALLOW_REGISTER=0` 可关闭）；token 无吊销，生产需接 OIDC/SSO。
- 纯浏览器（本地模式）导入装配 STEP 仍会丢面颜色；服务端模式已通过 OCP 转换器修复，详见
  [diagnostics/FINDINGS.md](diagnostics/FINDINGS.md)。转换器首次安装约 650 MB（Python + OCP）。
- 大网格（STEP 导入）仍整包存进文档 JSON，单次保存可达数十 MB；后续应外置到对象存储。
