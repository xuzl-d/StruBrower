局部特写：接口撑得住多细

补了哪三处接口

原缺口补的接口效果
1. 放样没有参数化截面
已补		 loft.sections[] 支持 ellipse{rx,ry,power} / airfoil{chord,thickness,le,camber} / profile，外加每段的 offset、twist、points。 机身从 22 截面 × 32 点（1,408 个数字）变成 24 行 {z, ellipse, offset}；翼型不再手推 NACA 公式。内核负责采样，点数天然对齐，没有接缝。
2. 没有镜像
已补		 pattern: { type:'mirror', axis:'y', center? }。内核做反射矩阵 + 翻转三角形绕序 + 法线取反。 机翼 / 小翼 / 平尾只写一侧。这类"左右各写一遍、translate 符号翻错也不报错"的静默失败彻底消掉了（测试里有 signedVolume > 0 兜底，保证镜像件法线仍朝外）。
3. 没有涂装
已补		 addDecal { text | image, width, height, position, normal }，落成独立的 primitive.kind:'decal' 构件（不参与布尔）。 「AIRBUS A350」和垂尾上的「A350」直接给文字、宽高、朝向即可。MeshBasicMaterial + 关闭色调映射，暗部也清晰。

这三处缺口，第二轮补掉了

缺口补法现在能做什么
1. 没有倒圆 / 抽壳 特征级 fillet / shell：盒体走专用构造器，其它凸体用「内缩 r + 半径 r 的球滚一遍」；抽壳 = 实体 − 内缩实体，开放面把内腔沿该方向补切一刀。 台基、额枋、檐口板、杯、管壳、箱体一行写完。见 diagnostics/modifiers/。
2. 曲面不能偏移 offset：每个顶点解「相邻各面都平移 d」的超定方程（最小二乘 + 正则项）。棱角处是三面相交的精确解，曲面上退化成等距面。 机身放样抽 0.02 蒙皮：1,532 → 5,501 面、88 ms，壁厚均匀。
3. 阵列单段 64 个 上限提到 192。 一排 90 个舷窗写在同一个特征里（代价：求值约 1 秒）。

仍未解决的：倒圆只对凸体成立（非凸件会被原样跳过）、布尔之后的新棱仍是尖的、变半径圆角与融合式翼梢需要 B-rep 级曲面圆角。

结论

  • 瓶颈从"接口"变成了"参数"。补完三处接口后，同一架飞机的特征树只剩 670 个数字，一次写得完；剩下的"像不像"取决于模型会不会摆参数，而不是接口能不能表达。
  • 垂尾这一课：几何直觉比接口更值钱。第一版按「前缘直线 + 弦长递减」写，后缘就前倾成三角形；改成「后缘钉在竖直面 x = -28.8、弦长 10 m → 3 m」，前缘自然得到 33° 后掠，立刻就像了。这类知识应该写进提示词，而不是指望模型自己推。
  • 下一步最该补的是 fillet 与 blend。参数化截面解决的是"体积"，倒圆解决的是"接缝"——后者现在是最大的观感短板。

已加入设计库（案例库）

  • 造型对话框 →「模板」下拉里新增 A350 客机（1:10）（也可以在「添加特征」区一键套用），默认 6.7 m 长的展示模型，代码里传 scale: 1 就是真实尺寸。
  • 特征树在 shared/models/aircraft-a350.json，与本页的离线出图同源；贴花（addDecal）是独立构件，模型库只取实体。
  • scripts/template-test.ts 会把每个模板都跑一遍 applyOps → buildElementModel，防止"点一下模板就崩"。

复现：npm run aircraft
