三个曲面修饰：倒圆 / 抽壳 / 偏移

补掉造型内核最后三处"看得见"的缺口：棱边圆角、薄壁壳体、面偏移，外加把阵列单特征上限从 64 提到 192。

实现：src/bim/solid.ts（求值）· server/ai/solid.js（校验）· 复现命令 npm run modifiers
倒圆
内缩 r + 滚球

盒体走专用构造器（真 R 圆角），其它凸体用「内缩 r，再用半径 r 的球滚一遍」——即 P ⊕ 球(r)，外形尺寸不变。

抽壳
真壁厚

实体减内缩实体；开放面把内腔沿该方向再补一刀，内腔穿出、侧壁高度不变，杯口不会矮一截。

偏移
按面推，不按点缩

每个顶点解「相邻各面都平移 d」的超定方程，棱角处是三面相交的精确解，曲面上退化成等距面。

1 · 倒圆：同一批形状，有没有 fillet

{ "shape": "box", "width": 0.8, "depth": 0.55, "height": 0.45, "fillet": 0.09 }
{ "shape": "cylinder", "radius": 0.3, "height": 0.5, "fillet": { "radius": 0.07, "segments": 24 } }
做法为什么
box → 专用构造器 盒体有现成的 buildRoundedBox（平面 + 真正的 R 圆角、竖直方向切层），比滚球采样的面片干净得多。
其它凸体 → 内缩 + 滚球 P ⊕ 球(r) = conv(各顶点球)：把内缩后的每个顶点撒一圈球面点取凸包，得到的就是精确的滚球倒圆。平面棱角变成 R 圆柱面，三棱交汇的角变成球面。
非凸体 → 原样跳过 上面那个恒等式只在凸体上成立。非凸几何滚一遍会变成它自己的凸包，把孔、凹槽全填掉——所以内核宁可不动，也不近似。

2 · 抽壳：杯、管壳与壁厚

{ "shape": "box", "width": 0.86, "depth": 0.86, "height": 0.72,
  "fillet": 0.06, "shell": { "thickness": 0.07, "open": "z+" } }

开放面的处理值得记一笔：直觉做法是"切掉顶上一层"，但那样会连侧壁一起削掉一截，杯口就矮了一个壁厚。 这里改成把内腔沿开口方向再平移一个壁厚补切一刀——内腔正好穿出顶面，其余五面的壁厚仍是 t。 封口壳与开口壳的体积差刚好是那一层顶壁（2.168 → 1.844 m³，壁厚 0.1、边长 2）。

3 · 偏移：把面推出去 / 收回来

偏移不能用"顶点沿法向走 d"来实现：盒子的角上三条棱法向不同，沿平均法向走 d 会让每个面只推出 d/√3（差 42%）。正确做法是让顶点同时满足"相邻各面都平移了 d"，这是一个超定线性方程组， 用最小二乘解（加一点正则项防曲面处退化）：

M = Σ nᵢnᵢᵀ + λI ,  b = d·Σ nᵢ ,  Δ = M⁻¹b

平面棱角上正好三面相交 → 精确解；圆柱、放样这类曲面上相邻面近乎平行，解退化成沿法向偏移， 而法向偏移就是曲面的等距面——两种情形都落在同一个公式里。

4 · 阵列：一排 90 个孔写在同一个特征里

代价要说清楚。实例数是乘在几何上的：90 个窗切在一块板上，求值约 1.0 秒（其余步骤不变）。 阵列上限提到 192 是为了"写得下"，日常仍建议 ≤ 32；真要一排 90 个，把 segments 降到 12–14 能省一半。

6 · 仍然做不到的

  • 变半径圆角 / 融合式翼梢：滚球只能给等半径 R。要"根部 R20、梢部 R3"的过渡，需要 B-rep 级的曲面圆角。
  • 布尔之后的倒角：fillet 作用在特征自己的几何上，切除产生的新棱仍是尖的。要圆就把 fillet 写在切除之前。
  • 2D 轮廓倒圆：凹多边形 prism 的平面角仍需手写 profile 或换 roundedBox。
  • 贴图材质：只有独立平面的贴花，没有 UV 贴图与纹理，蒙皮分缝 / 铆钉排还做不出来。
